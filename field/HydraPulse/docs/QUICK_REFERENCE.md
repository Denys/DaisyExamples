# HydraPulse Beat | quick reference

**First beat:** Shift + 1 selects Hammer → tap steps → K1–K4 shape it → tap/release SW1.
Key numbers are provisional logical positions; qualify the real Field mapping first.

| Control | Meaning |
|---|---|
| K1 / K2 / K3 / K4 | Tune / Decay / Character / Level of selected voice |
| K5 / K6 / K7 / K8 | Tempo / Swing / Drive / Master |
| SW1 tap-release | Play / Stop |
| SW2 held | Shift palette; release always returns Home |
| Both switches 500 ms | Panic |
| Step tap-release | Toggle |
| Step hold 400 ms | Toggle accent; never delete on release |

**Shift:** 1–4 select voices; 5=A; 6=B; 7=edit Fill; 8=hold Fill;
9–12=mutes; 13=hold clear one second while stopped;
14/15=previous/next tutorial preview; 16=confirm load while stopped.

A/B changes play at the next step 1, editing immediately. Fill borrows the third bank
at the current step position. All banks share voice settings and globals.
Knobs use pickup; cross the stored target. Tutorial load preserves Master.

**No Save, Undo, external clock following, audio-through or live CV/Gate integration.**
MIDI channel 10 notes 36/38/42/39 trigger Hammer/Crack/Steel/Arc.
