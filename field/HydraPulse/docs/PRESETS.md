# Tutorial presets and progressive lessons
These are original authored patterns and settings from `presets/tutorials.json`. No commercial factory pattern was transcribed. Runtime IDs are 0–7. All banks share voice parameters; Master is retained when loading.
Load only while stopped: hold SW2, use key 14/15 to preview, then key 16 to confirm. Release SW2 to return Home. Save does not exist yet; loading discards edits.
Grid legend: `.` empty, `x` active, `X` accented. Positions run left to right from 01 to 16.
## 0. Blank Canvas
**Lesson:** Build a rhythm from silence.
**Build, then remove.** Select Hammer, tap steps 1/5/9/13, then select Crack and tap 5/13. Listen, then remove one kick. The goal is to learn the editing surface, not a finished arrangement.
**Next exercise:** Hold one existing kick step for 400 ms. Compare that accent to its neighbors.

## Host WAV scenario
Each ten-second host render starts the tutorial, queues B at 3 s, requests Fill at 5 s, releases Fill at 6 s, and panics at 7 s. The final seconds test silence. Master is 0.70 for the renderer, not a value loaded by the tutorial. Blank Canvas is intentionally silent.
The supplied WAVs are native C++ renders, not recordings from Daisy Field. Matching hashes show repeatability in the tested host build, not bit equality across processors.
## Blank notes sheet
Record the voice values above, then three sixteen-step grids per voice. Include tempo, swing, drive, master, mutes, the firmware hash and anything learned during the lesson. A/B changes occur on the next bar; Fill continues the current phase.
