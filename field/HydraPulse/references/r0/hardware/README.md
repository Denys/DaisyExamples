# Hardware notes

Hardware-specific mappings are deliberately absent from R0 unless directly measured or taken from the verified official BSP.

P0 will add:

- Field serial number / hardware revision where available;
- test fixture and instruments;
- key scan-index map;
- knob endpoint/direction table;
- CV input calibration observations;
- CV output code/voltage measurements;
- Gate I/O levels;
- audio loopback fixture details;
- callback probe point / GPIO method.
