Find all local Daisy examples and projects, understand their documented role and source structure, inspect original code, and trace each description to frozen source files.

## Capabilities and Constraints

Search, platform/group filters, chapter navigation, original source reader, build recipes, source hashes, explicit scope and exclusions. Current-session inventory evidence remains separate from historical build claims and from hardware validation.

## Evidence on Hand

Local README, CONTROLS, CHECKPOINT, manifests, original C/C++ source, library headers, repository metadata. No firmware execution, listening or hardware measurement is part of this task.
